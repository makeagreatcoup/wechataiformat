## 🔧 技术实现

### 主题配置结构

每个主题包含以下配置:

```javascript
{
    h1: { background, color, icon, shadow },
    h2: { background, color, icon, shadow },
    h3: { dotColor, dotShadow, color },
    blockquote: { background, borderColor, color, shadow, showQuote },
    listIcon: '符号',
    listIconColor: '#颜色',
    codeInline: { background, color, shadow },
    codeBlock: { background, color, shadow },
    link: { color, underlineColor },
    table: { headerBackground, headerColor, evenRowBg, hoverBg, shadow },
    hr: { background, icon, iconColor },
    img: { radius, shadow },
    base: { fontSize, lineHeight, paragraphSpacing, containerWidth }
}
```

### CSS动态绑定

使用 `attr()` 函数从元素读取data属性:

```css
.wechat-preview h1::before {
    content: attr(data-icon) " ";
}

.wechat-preview ul li::before {
    content: attr(data-icon) " ";
    color: attr(data-icon-color);
}

.wechat-preview a::after {
    background: var(--underline-color);
}
```

### JavaScript应用样式

```javascript
// H1标题
h1.style.background = s.h1.background;
h1.style.color = s.h1.color;
h1.setAttribute('data-icon', s.h1.icon);

// 链接
link.style.setProperty('--underline-color', s.link.underlineColor);
```

## 💡 使用建议

1. **根据文章类型选择主题**
   - 技术文章 → 💻 科技蓝调 或 ⚪ 极简单纯
   - 情感文章 → 🌸 清新可爱 或 🍁 温暖秋日
   - 商业文章 → 💼 商务专业
   - 创意文章 → 🎨 梦幻渐变

2. **预览测试**
   - 切换不同主题查看效果
   - 使用手机/桌面预览模式对比
   - 复制到微信编辑器实际测试

3. **不可自定义的原因**
   - 每个主题都是精心设计的完整视觉系统
   - 简单的颜色调整会破坏整体协调性
   - 6个主题已覆盖大部分使用场景
