# 公众号排版工具 🎨

一个功能强大的微信公众号文章排版工具,支持Markdown实时编辑、多套样式主题切换、自定义样式设置和一键复制到微信编辑器。

## 功能特点 ✨

- **实时预览** - 左侧编辑Markdown,右侧实时查看渲染效果
- **多套样式** - 内置4种精美样式主题(经典、商务、文艺、极简)
- **自定义设置** - 灵活调整字体大小、颜色、行高、间距等细节
- **一键复制** - 快速复制格式化内容到微信公众号编辑器
- **设备切换** - 支持手机/桌面预览模式切换
- **完全离线** - 纯HTML/CSS/JS实现,无需服务器

## 使用说明 📖

### 基本流程

1. **输入内容** - 在左侧编辑器输入或粘贴Markdown格式的文章
2. **选择样式** - 在中间面板选择喜欢的样式主题
3. **自定义设置** - 点击"自定义样式"按钮调整细节
4. **复制导出** - 点击"复制到微信编辑器"按钮
5. **粘贴发布** - 在微信公众号编辑器中粘贴(Ctrl+V)

### 支持的Markdown语法

- **标题** - `# 一级标题`、`## 二级标题`、`### 三级标题`
- **段落** - 直接输入文本,段落间空行
- **粗体** - `**粗体文本**`
- **斜体** - `*斜体文本*`
- **链接** - `[链接文字](URL)`
- **图片** - `![图片描述](图片URL)`
- **引用** - `> 引用内容`
- **代码** - `` `行内代码` `` 或 \```代码块\```
- **列表** - `- 无序列表` 或 `1. 有序列表`
- **表格** - 标准Markdown表格语法

### 样式主题说明

| 主题 | 特点 | 适用场景 |
|------|------|----------|
| 经典样式 | 简洁大方 | 日常文章、通用内容 |
| 优雅商务 | 商务专业 | 商业文章、深度分析 |
| 清新文艺 | 文艺清新 | 情感文章、生活记录 |
| 极简主义 | 极简单纯 | 技术文章、干货分享 |

### 自定义设置项

- **标题颜色** - 各级标题的文字颜色
- **正文字体大小** - 12-24px可调
- **正文行高** - 1.0-3.0倍行高
- **段落间距** - 段落之间的间距
- **引用样式颜色** - 引用块左边框颜色
- **链接颜色** - 超链接文字颜色
- **代码背景色** - 代码块背景颜色
- **容器宽度** - 文章内容宽度(300-800px)

## 快捷键 ⌨️

- `Ctrl + S` - 快速复制到剪贴板
- `Ctrl + V` - 在编辑器中粘贴内容
- `ESC` - 关闭设置弹窗

## 核心代码说明 💡

### 1. 状态管理 (app.js:2-7)

### 2. 样式主题定义 (app.js:9-67)

### 3. 实时预览机制 (app.js:245-277)

使用防抖函数优化性能,避免频繁渲染。Markdown解析后动态应用样式规则。

- **YAGNI**: 仅实现核心功能,避免过度设计
- **DRY**: 样式主题系统统一管理,代码复用率高
- **单一职责**: 每个函数专注单一功能

## 常见问题 ❓

### Q: 为什么复制到微信后样式有差异?

A: 微信编辑器对CSS支持有限,工具已做最大兼容优化。建议使用微信支持的内置样式属性。

### Q: 如何保存我的自定义设置?

A: 当前版本自定义设置仅在单次会话有效。刷新页面后会恢复默认。

### Q: 支持导出为HTML文件吗?

A: 当前版本仅支持复制到剪贴板,未来版本可添加导出功能。

### Q: 图片如何处理?

A: 使用Markdown图片语法,需确保图片URL可公开访问。建议先将图片上传到图床。
