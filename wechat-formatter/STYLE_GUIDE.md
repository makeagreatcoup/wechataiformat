# 特殊样式效果说明

## 📋 新增样式概览

已为所有Markdown标签添加精美的装饰效果,让文章排版更加生动专业。

## 🎯 标签样式详解

### 1. 标题样式 (H1/H2/H3)

#### H1 - 主标题
- **渐变背景**: 紫色到粉色的渐变 (linear-gradient)
- **图标装饰**: 前面添加 ✨ emoji
- **阴影效果**: 0 4px 15px 的柔和阴影
- **圆角边框**: 8px 圆角
- **居中对齐**: 文字居中显示

#### H2 - 二级标题
- **渐变背景**: 粉色到红色的渐变
- **图标装饰**: 前面添加 📌 emoji
- **圆角设计**: 6px 圆角
- **阴影效果**: 0 3px 10px 的阴影

#### H3 - 三级标题
- **圆点装饰**: 左侧渐变圆点标记
- **圆点阴影**: 外圈有半透明光晕效果
- **间距设计**: 左侧留白20px

### 2. 引用块样式 (blockquote)

- **渐变背景**: 黄色系渐变 (#ffeaa7 → #fdcb6e)
- **装饰引号**: 左上角添加半透明双引号 (")
- **左侧边框**: 5px 实色边框
- **圆角阴影**: 8px 圆角 + 阴影效果
- **文字颜色**: 深灰色 (#2d3436)
- **特殊处理**: 内部段落取消首行缩进

### 3. 列表样式 (ul/ol)

#### 无序列表 (ul)
- **自定义图标**: 使用 `▸` 符号替代默认圆点
- **图标颜色**: 紫色 (#667eea)
- **图标大小**: 18px 加粗显示
- **左侧间距**: 30px 留白

#### 有序列表 (ol)
- **数字样式**: 使用 `::marker` 伪元素
- **数字颜色**: 紫色加粗
- **左侧间距**: 30px 留白
- **行高设置**: 1.8 倍行高

### 4. 代码样式

#### 行内代码 (code)
- **渐变背景**: 黄色系渐变
- **圆角设计**: 4px 圆角
- **阴影效果**: 0 2px 5px 浅阴影
- **文字颜色**: 深色 (#2d3436)
- **内边距**: 3px 8px

#### 代码块 (pre)
- **深色背景**: 黑色到深灰色渐变
- **圆角设计**: 8px 圆角
- **边框效果**: 1px 半透明白色边框
- **文字颜色**: 浅灰色 (#dfe6e9)
- **阴影效果**: 0 4px 15px 深阴影
- **内边距**: 20px

### 5. 链接样式 (a)

- **文字颜色**: 蓝色 (#0984e3)
- **下划线动画**: 悬停时从左到右展开的渐变下划线
- **渐变效果**: 紫色到粉色的渐变下划线
- **过渡动画**: 0.3s 平滑过渡
- **字体加粗**: font-weight: 500

### 6. 表格样式 (table)

- **整体阴影**: 0 4px 15px 的阴影
- **圆角设计**: 8px 圆角 (overflow: hidden)
- **表头样式**:
  - 紫色渐变背景
  - 白色文字
  - 15px 内边距
- **单元格样式**:
  - 底部边框: 1px #eee
  - 内边距: 12px 15px
  - 无左边框
- **斑马纹**: 偶数行浅灰背景
- **悬停效果**: 鼠标悬停时背景变色

### 7. 分隔线样式 (hr)

- **渐变效果**: 从透明到紫色再到透明的渐变
- **高度**: 3px
- **中心装饰**: 中间添加 ✦ 星星符号
- **星星背景**: 白色背景遮挡线条
- **星星颜色**: 紫色 (#667eea)

### 8. 图片样式 (img)

- **圆角设计**: 8px 圆角
- **阴影效果**: 0 4px 12px 阴影
- **居中显示**: 自动水平居中
- **响应式**: max-width: 100%

## 🎯 样式应用规则

### CSS优先级
1. 内联样式 (JS动态设置) - 最高优先级
2. CSS类样式 (.wechat-preview 标签)
3. 浏览器默认样式 - 最低优先级

### JavaScript应用逻辑
- **字体大小**: 直接设置 `fontSize`
- **行高**: 直接设置 `lineHeight`
- **颜色**: 通过 `querySelectorAll` 批量设置
- **特殊元素**: H2边框、引用块边框单独处理

## 📱 微信兼容性

### 支持的样式
- ✅ 渐变背景 (linear-gradient)
- ✅ 圆角 (border-radius)
- ✅ 阴影 (box-shadow)
- ✅ 伪元素 (::before, ::after)
- ✅ 伪类 (:hover, :nth-child)
- ✅ 过渡动画 (transition)

### 注意事项
- 某些CSS3特性在旧版微信中可能不完全支持
- 建议使用最新版微信客户端测试
- 图片需要外链,不能使用本地图片

## 🔄 自定义设置

用户可以通过"自定义样式"按钮调整:
- 标题颜色
- 正文字体大小 (12-24px)
- 正文行高 (1.0-3.0)
- 段落间距 (10-50px)
- 引用样式颜色
- 链接颜色
- 代码背景色
- 容器宽度 (300-800px)

## 💡 设计原则

### 1. KISS (简单至上)
- 每个标签样式专注单一视觉效果
- 避免过度装饰影响阅读

### 2. 一致性
- 所有元素使用统一的色彩体系
- 圆角、阴影保持一致风格

### 3. 可读性优先
- 行高、间距经过优化
- 颜色对比度符合WCAG标准

### 4. 视觉层次
- H1/H2/H3 有明显的视觉层级
- 通过颜色、大小、装饰区分重要性
