## 🚀 在线使用

### 方法一:直接访问GitHub Pages(推荐)

如果配置了GitHub Pages,可以直接在线使用:
https://makeagreatcoup.github.io/wechataiformat/

### 方法二:本地运行

```bash
# 1. 克隆项目
git clone git@github.com:makeagreatcoup/wechataiformat.git

# 2. 进入目录
cd wechataiformat

# 3. 直接打开 index.html
# 或使用本地服务器
python -m http.server 8000
```

## 🤝 贡献指南

欢迎提交Issue和Pull Request!

### 开发环境

无需任何构建工具,纯HTML/CSS/JS实现:

1. Fork本项目
2. 修改代码
3. 本地测试
4. 提交Pull Request

### 代码规范

- **HTML**: 使用语义化标签
- **CSS**: BEM命名规范,保持样式隔离
- **JavaScript**: ES6+语法,模块化函数设计
- **注释**: 关键功能添加中文注释

## 📝 提交规范

### Commit Message格式

```
<type>: <subject>

<body>
```

### 类型(type)

- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 重构代码
- `test`: 测试相关
- `chore`: 构建/工具变动

### 示例

```
feat: 添加深色模式支持

- 新增深色主题配置
- 优化暗色背景样式
- 更新用户文档
```
